# Data DictionaryThis document describes the key fields used in the Insurance Claims Analytics project.---## Policy Information| Field | Description | Data Type ||---|---|---|| policy_id | Unique identifier for the insurance policy | Text || policy_type | Type of insurance policy | Text || sum_insured | Maximum insured amount under the policy | Currency || policy_start_date | Date when the policy became active | Date || claim_date | Date associated with the claim | Date |---## Patient Demographic Information| Field | Description | Data Type ||---|---|---|| gender | Gender of the insured individual | Text || age | Age of the insured individual | Integer || marital_status | Marital status | Text || state | State of residence | Text || city | City of residence | Text || pincode | Postal code | Text || occupation_type | Occupation category | Text || annual_income_inr | Annual income in Indian Rupees | Currency |---## Medical Risk Factors| Field | Description | Data Type ||---|---|---|| bmi | Body Mass Index | Decimal || bmi_group | BMI classification category | Text || bmi_risk | BMI risk indicator | Text || tobacco_usage | Tobacco consumption category | Text || tobacco_risk | Tobacco risk indicator | Text || alcohol_units_per_week | Weekly alcohol consumption units | Integer || physical_activity_level | Physical activity level category | Text || diet_type | Diet type category | Text || has_diabetes | Diabetes indicator | Boolean || has_hypertension | Hypertension indicator | Boolean || family_history_cardiac | Family history of cardiac conditions | Boolean || stress_level_score | Stress level score | Integer |---## Medical Risk Score| Field | Description | Data Type ||---|---|---|| chronic_risk | Chronic conditions risk indicator | Text || family_history_risk | Family history risk indicator | Text || medical_risk_score | Composite medical risk score (0–7) | Integer || medical_risk_normalized | Normalized medical risk score (0–1) | Decimal |---## Claim & Hospital Information| Field | Description | Data Type ||---|---|---|| hospital_name | Name of the hospital | Text || hospital_tier | Hospital tier classification | Text || room_category | Room category | Text || icu_days | Number of days in ICU | Integer || length_of_stay | Total length of hospital stay in days | Integer || cashless_claim | Cashless claim indicator | Boolean || agent_channel | Agent or distribution channel | Text |---## Financial Fields| Field | Description | Data Type ||---|---|---|| hospital_bill_amount | Hospital bill amount | Currency || pre_hospitalization_expense | Expenses before hospitalization | Currency || post_hospitalization_expense | Expenses after hospitalization | Currency || non_payable_items | Non-payable claim items | Currency || deductible_amount | Deductible amount | Currency || co_pay_amount | Co-payment amount | Sum Insured) | Decimal || cost_per_day | Cost per day (Hospital Bill ÷ Length of Stay) | Currency || claim_delay | Claim delay in days (Claim Date - Policy Start Date) | Integer || out_of_pocket | Out of pocket expense (Deductible + Co-pay + Non-payable) | Currency || income_to_claim_ratio | Income to claim ratio | Decimal |---## Normalized Features| Field | Description | Data Type ||---|---|---|| claim_ratio_normalized | Normalized claim ratio | Decimal || cost_per_day_normalized | Normalized cost per day | Decimal || claim_delay_normalized | Normalized claim delay | Decimal || out_of_pocket_normalized | Normalized out of pocket expense | Decimal || income_to_claim_risk_normalized | Normalized income to claim risk | Decimal |---## Overall Risk Scoring| Field | Description | Data Type ||---|---|---|| overall_claim_risk_score | Composite risk score (0–1) | Decimal || claim_risk_level | Risk classification (Low / Medium / High / Potential Anomaly) | Text |---## Anomaly Detection Fields| Field | Description | Data Type ||---|---|---|| claim_ratio_zscore | Z-score for claim ratio | Decimal || cost_per_day_zscore | Z-score for cost per day | Decimal || claim_delay_zscore | Z-score for claim delay | Decimal || total_claim_amount_zscore | Z-score for total claim amount | Decimal || anomaly_count | Number of Z-scores exceeding +3 (0–4) | Integer || potential_anomaly | Anomaly classification (Normal / Anomaly) | Text |---## SummaryThis Data Dictionary covers all key fields used in the Insurance Claims Analytics project.The
