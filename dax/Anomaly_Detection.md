# Anomaly Detection DAX MeasuresThis document contains the DAX measures used for statistical anomaly detection in the Insurance Claims Analytics project.---## Z-Score Calculations### Claim Ratio Z-Score```daxClaim_Ratio_ZScore = VAR MeanVal = AVERAGE(claims[Claim_Ratio])VAR StdDevVal = STDEV.P(claims[Claim_Ratio])RETURNDIVIDE([Claim_Ratio] - MeanVal, StdDevVal, 0)Cost Per Day Z-ScoreCost_Per_Day_ZScore = VAR MeanVal = AVERAGE(claims[Cost_Per_Day])VAR StdDevVal = STDEV.P(claims[Cost_Per_Day])RETURNDIVIDE([Cost_Per_Day] - MeanVal, StdDevVal, 0)Claim Delay Z-ScoreClaim_Delay_ZScore = VAR MeanVal = AVERAGE(claims[Claim_Delay])VAR StdDevVal = STDEV.P(claims[Claim_Delay])RETURNDIVIDE([Claim_Delay] - MeanVal, StdDevVal, 0)Total Claim Amount Z-ScoreTotal_Claim_Amount_ZScore = VAR MeanVal = AVERAGE(claims[Total_Claim_Amount])VAR StdDevVal = STDEV.P(claims[Total_Claim_Amount])RETURNDIVIDE([Total_Claim_Amount] - MeanVal, StdDevVal, 0)Anomaly CountAnomaly_Count = (IF([Claim_Ratio_ZScore] >= 3, 1, 0)) +(IF([Cost_Per_Day_ZScore] >= 3, 1, 0)) +(IF([Claim_Delay_ZScore] >= 3, 1, 0)) +(IF([Total_Claim_Amount_ZScore] >= 3, 1, 0))Potential Anomaly ClassificationPotential_Anomaly = IF([Anomaly_Count] >= 2, "Anomaly", "Normal")Z-Score Validation MeasuresCheck Z-Score DistributionZScore_Mean_Claim_Ratio = AVERAGE(claims[Claim_Ratio_ZScore])ZScore_StdDev_Claim_Ratio = STDEV.P(claims[Claim_Ratio_ZScore])Count of Z-Scores > 3Count_Claim_Ratio_ZScore_GT3 = CALCULATE(COUNT(claims[Claim_Ratio_ZScore]), claims[Claim_Ratio_ZScore] >= 3)Last Updated: September 2025
